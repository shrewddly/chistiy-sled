# Чистый след — бесплатный Telegram-бот самопроверки

Ищет информацию о **вас** в открытых источниках и помогает её закрыть. Всё на кнопках — команды писать не нужно.

Бот: **Чистый след**, `@chistiy_sled_bot`. Работает круглосуточно на Render: https://chistiy-sled.onrender.com

## Что умеет

- 📧 **Утечки по email** — XposedOrNot (риск, что утекло, крупные утечки) + LeakCheck (источники и категории данных).
- 🕵️ **Ник** — поиск в LeakCheck по вашему логину.
- 🔑 **Пароль** — проверка через HIBP Pwned Passwords (бесплатно, k-anonymity). Бот удаляет сообщение с паролем из чата; есть полностью локальный вариант `tools/check_password.bat`.
- 🔎 **Поисковые следы** — готовые запросы в Google, Яндекс, DuckDuckGo, соцсети, документы, GitHub.
- 🌐 **Мой домен** — поддомены по публичным CT-логам (crt.sh) + Shodan.
- 🧹 **План зачистки** — 10 шагов с прогрессом.
- 📄 **Шаблоны заявлений** — сайту, хостеру, поисковикам/РКН.
- 📊 **Отчёт** — сводка по проверке.
- 🗑 **Удаление данных** — `/delete` стирает согласие, отчёт и прогресс.

Перед первым действием бот просит подтвердить, что данные — ваши. Чужих людей он не ищет.

**Приватность:** email не сохраняется; в базе только факт согласия, число утечек/источников, риск, дата проверки и прогресс чек-листа. На бесплатном Render файл SQLite временный и очищается при перезапуске.

Честно: «стереть все следы» из утечек невозможно — дампы не отзываются. Бот даёт реальный максимум: сменить доступы, убрать из выдачи, подать заявления и довести это до конца.

## Запуск (Windows)

1. В Telegram: [@BotFather](https://t.me/BotFather) → `/newbot`.
   - Имя: `Чистый след`
   - Username: `chistiy_sled_bot` (если занят — любой со словом sled/clean и окончанием `bot`)
2. Скопируйте `.env.example` в `.env` и впишите токен:
   ```
   BOT_TOKEN=123456:AA...
   ```
3. Двойной клик по `start.bat`. Первый запуск сам поставит зависимости.

Не запускайте `start.bat`, пока бот работает в облаке: два экземпляра конфликтуют в Telegram.

## Деплой на Render

Репозиторий: https://github.com/shrewddly/chistiy-sled. Blueprint `render.yaml`, web-сервис free, health-check `/health`, старт `python bot.py`. Токен задаётся только в Environment Variables на Render. Самопинг каждые 10 минут не даёт бесплатному инстансу засыпать.

Красиво оформить в BotFather:
- `/setuserpic` — загрузите `assets/avatar.png`
- `/setdescription` — `Проверяю, что о вас видно в сети: утечки, поисковые следы, домены. Бесплатно. Только ваши данные.`
- `/setabouttext` — `Бесплатная самопроверка цифрового следа: утечки по email, ники, пароли, поиск, домены и план зачистки.`

## Файлы

- `bot.py` — бот и интерфейс (aiogram 3)
- `checks.py` — XposedOrNot, LeakCheck, HIBP Pwned Passwords, crt.sh, поисковые запросы
- `cleanup.py` — тексты плана зачистки
- `db.py` — SQLite: согласие, прогресс, последняя проверка (email не хранится)
- `templates/` — заявления
- `tests/` — тесты парсеров и приватности (`python -m unittest discover -s tests`)
- `tools/check_password.bat` — локальная проверка пароля
- `assets/` — аватар и баннер
- `data/bot.db` — создаётся автоматически
